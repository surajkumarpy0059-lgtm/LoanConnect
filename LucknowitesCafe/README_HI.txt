LUCKNOWITES CAFE Android app — native Kotlin starter build.

Features: customer menu, category browsing, cart, quantity controls, total and demo order flow. Admin demo PIN: 1234.
Important limitations: orders are kept only in app memory; no cloud sync, secure production admin authentication, inventory management or UPI gateway yet. Multiple listed prices are shown as Option 1/2/3 because sizes were not specified.
The GitHub Actions workflow builds a debug APK when manually started or when files in this folder change. The APK is uploaded as a workflow artifact.
